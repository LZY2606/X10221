# 流式边界室离线案例包

该案例是合成 FCS-like 事件流，用于复核补偿、asinh 变换、门控系谱、百分比分母、多候选和失效传播。

固定叙事包含：
- E004：位于 Lymphocytes 矩形 FSC 最小边界。
- E005：位于 CD4/CD8 共享多边形边。
- E006：FITC ADC 饱和且 PE 超普通线性范围。
- `mat-v2-near-singular`：近奇异补偿矩阵，导入时不主动求逆。
- 后续修订生成奇异矩阵、参数修订、门改名、上游门修订、局部 PE 源数据改动和同版本冲突。

所有原始值保留单位或坐标基准；补偿值和 asinh 坐标只存在于派生层。
