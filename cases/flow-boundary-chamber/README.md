# 流式边界室：补偿矩阵、门控系谱与细胞群不确定性

离线领域案例包。叙事主线：流式平台导入 FCS 事件、单染对照和门控草案，
逐步复核从原始信号到最终细胞群的每次变换。

## 文件
- `fcs_events.json` — 原始通道值（含极端信号、边界点、不可转换值），逐事件保留原始表示与单位/坐标基准
- `single_stain_controls.json` — FITC / PE 单染对照
- `spillover.json` — spillover 元数据与近奇异溢漏矩阵
- `transforms.json` — logicle 变换参数（含坐标基准）
- `gating_draft.json` — 门多边形与父子关系（含嵌套门与边界规则）
- `scenario.json` — 重放脚本：基线 → 参数修订 → 局部源改动 → 冲突人工裁定

## 覆盖的边界情形
矩阵奇异、极端信号、边界点、门嵌套改名、上游过期传播、同版本并发修改。
