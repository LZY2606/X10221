# 流式边界室：补偿矩阵、门控系谱与细胞群不确定性

这是一份**领域专用**离线案例包，不是通用表格。它围绕一次真实形态的复核叙事组织：

1. 流式平台导入 FCS 事件（`case.json#events`，原始 channel-count 与量程/18bit 表示保留）、
   单染对照与 spillover 元数据（`spillover_meta`）、补偿矩阵（基线/近奇异/严格奇异三套）、
   asinh 变换参数（基线与修订）、门多边形（含坐标基准与边界规则）和父子链接（含改名版本）。
2. 初始复核核对六类材料是否**分开版本化**。
3. 重放依次经过：近奇异与严格奇异补偿矩阵（禁止默默求逆、保留全部合法候选）、
   极端/溢出信号（E25 超量程不裁剪）、边界点（E24 恰落在 live 下边界，inclusive）、
   门嵌套改名（CD3+ → CD3+ T cells，身份稳定）、上游门修订导致下游结果**标记过期而不覆盖**、
   以及同 revision 的并发人工决定（后提交者收到 409 与双方差异）。
4. 审阅页路径：通道散点 → 门树 → 补偿前后差异 → 每群分母来源（钉住父群结果版本）→ 两草案并排。

所有领域量带单位或坐标基准；无法规范化的值（如溢出 300000）留在原位置并附诊断。
`expectations` 段是机器可读取断言基线（结论、来源链、失效范围、稳定身份前缀）。

`controls/` 下保存单染对照与 spillover 导出的原始字节，导入时原样入库存档。
