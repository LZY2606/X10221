# 流式边界室：补偿矩阵、门控系谱与细胞群不确定性

流式平台导入 FCS 事件、单染对照和门控草案后，审阅者沿一条可见路径复核
从原始信号到最终细胞群的每次变换：

1. **导入**：原始通道值、spillover 元数据、补偿矩阵、变换参数、门多边形和
   父子关系分开版本化保存；原始表示原样保留，派生层才做规范化。
2. **首轮计算**：e15 恰好落在 Lymphocytes 门左边界（边界点 → 双候选），
   e16 的 FITC-A=300000 超出 18-bit 检测上限（极端信号 → 原值保留 + 诊断，
   不为画图而丢弃）。
3. **矩阵奇异**：补偿矩阵 v2 行列式≈1.4e-14，系统拒绝默默求逆，给出
   候选集（沿用 v1 / 单位矩阵 / 人工录入）等待裁定。
4. **门嵌套改名**：父门 CD3+ 改名为「CD3+ T 细胞」，子门 CD19+ 的既有
   结果标记过期而不覆盖。
5. **上游过期传播**：e09 的 FITC-A 录入修正只使 g-cd3/g-cd19 结果过期，
   g-lymph 结果保持有效。
6. **同版本并发修改**：两个窗口基于同一分支头提交冲突裁定，后提交者看到
   版本冲突及双方差异。

门的百分比分母始终钉住父群版本；修订上游门后下游结果标记过期而不覆盖；
无法唯一决定时全部合法候选与裁定分支一并保留。从审阅页做出的接受、否定
或参数调整都生成新事件；回到任意旧事件可恢复当时的依赖版本与可见结论。
